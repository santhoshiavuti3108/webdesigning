# Task3 : Temperature Converter

A simple and user-friendly web application that converts temperature values between different temperature units.

## 📌 About the Project

The Temperature Converter allows users to enter a temperature value and convert it between Celsius, Fahrenheit, and Kelvin.

## ✨ Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Simple and clean user interface
- Instant conversion using JavaScript
- Easy-to-use input and buttons
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
Temperature-Converter/
│
├── index.html
├── style.css
└── script.js
```

## ⚙️ How It Works

1. Enter a temperature value.
2. Select the input temperature unit.
3. Select the unit you want to convert to.
4. Click the **Convert** button.
5. The converted temperature will be displayed.
