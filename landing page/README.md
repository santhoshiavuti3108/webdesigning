#  task 1 : Landing Page

## 📌 Project Overview

This project is a responsive and user-friendly landing page created as part of my internship task.

The main purpose of this project is to practice and demonstrate the use of **HTML and CSS** to create a structured, attractive, and responsive web page.

The landing page contains a navigation bar, hero section, feature section, about section, contact section, and footer.

---

## 🎯 Objectives

- Create a clean and attractive landing page.
- Practice HTML page structure.
- Apply CSS styling and layouts.
- Create navigation links between different sections.
- Make the webpage responsive and user-friendly.
- Improve understanding of frontend web development.

---

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure of the webpage.
- **CSS3** – Used for styling, layout, colors, spacing, and responsiveness.

---

## 📂 Project Structure

```text
Landing-Page/
│
├── index.html
├── style.css
└── README.md
```

### Files Description

**index.html**
- Contains the complete structure of the landing page.
- Includes the navigation bar, hero section, features, about, contact, and footer sections.

**style.css**
- Contains all the styling for the webpage.
- Used for colors, fonts, spacing, buttons, layouts, and responsive design.

**README.md**
- Contains information about the project, technologies used, features, and project structure.

---

## ✨ Features

### 1. Navigation Bar
- Contains links to different sections of the webpage.
- Provides easy navigation throughout the landing page.

### 2. Hero Section
- Contains the main heading and introductory content.
- Includes a call-to-action button.

### 3. Explore Features Section
- Displays the main features of the webpage.
- Uses cards to present information clearly.

### 4. About Section
- Provides information about the purpose of the website/project.

### 5. Contact Section
- Provides contact-related information.
- Helps users easily find the required contact details.

### 6. Footer
- Contains the footer information of the webpage.

### 7. Responsive Design
- The layout is designed to work on different screen sizes.
- CSS media queries are used to improve the mobile experience.
