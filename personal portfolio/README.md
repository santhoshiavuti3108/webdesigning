# Task 2 : Personal Portfolio Website

## 📌 Project Overview

This project is a personal portfolio website created to showcase my skills, projects, education, achievements, and contact information in a simple and professional way.

The portfolio is designed to provide an overview of my technical skills and learning journey as a BTech Computer Science student.

The website has a clean and responsive design so that users can easily explore the different sections of the portfolio.

---

## 🎯 Objectives

- Create a personal portfolio website.
- Showcase my technical skills and projects.
- Present my education and learning journey.
- Provide information about my experience and achievements.
- Create an easy way for visitors to contact me.
- Practice frontend web development concepts.
- Learn how to organize and deploy a website using GitHub.

---

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure and content of the website.
- **CSS3** – Used for styling, layout, colors, spacing, and responsive design.
- **JavaScript** – Used to add interactive functionality to the website.
- **Git & GitHub** – Used for version control and project hosting.

---

## 📂 Project Structure

```text
Portfolio-Website/
│
```

### Files Description

**index.html**
- Contains the main structure of the portfolio website.
- Includes sections such as Home, About, Skills, Projects, Education, and Contact.

**style.css**
- Contains the styling and visual design of the website.
- Controls colors, fonts, spacing, layouts, buttons, and responsive design.

**script.js**
- Contains JavaScript functionality used to make the website interactive.

**README.md**
- Contains information about the portfolio project, technologies, features, and project structure.
